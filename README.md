# Learnova

An AI tutor that learns how you learn.

Built for BFWAI Hack26 — PS 03: Personalised AI Tutor for Learning AI.

## What it does

Learnova diagnoses a learner's background and goal, then routes 
them through a personalised AI curriculum — same content, different 
order, tiers, and framing per learner.

- Tailwind CSS, Framer Motion, Lucide
- TypeScript
